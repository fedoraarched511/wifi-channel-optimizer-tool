## 🎯 Why You Need This Tool

WiFi routers broadcast on channels – think of them as different lanes on a highway. When too many routers use the same lane, everything slows down. Many people never change their router's default channel, so congested areas (apartments, offices, neighborhoods) suffer from constant interference. This tool solves that problem by showing you the clearest lane instantly.

## 🖥️ Using the Tool

### 1️⃣ Scan Networks

Click the **"Scan"** button (or press `Ctrl+S`). The tool will:
- Detect your wireless adapter
- List every WiFi network in range
- Show signal strength, band (2.4 GHz or 5 GHz), and current channel

### 2️⃣ View Congestion

After scanning, you'll see two sections:

| Section | What It Shows |
|---------|---------------|
| **2.4 GHz Band** | Channel usage for channels 1–11 (most common for older devices) |
| **5 GHz Band** | Channel usage for channels 36–165 (faster, less congested) |

Each channel is displayed with a color-coded bar:
- 🟢 **Green** = Low congestion (ideal)
- 🟡 **Yellow** = Moderate congestion
- 🔴 **Red** = Heavy congestion (avoid)

### 3️⃣ Get Your Recommendation

The tool automatically calculates and displays your **best channel** at the top of the screen. A message like:

> **Recommended: Channel 6** – Only 2 networks nearby, excellent signal quality.

Write down this number.

## ⚙️ Applying Your New Channel

Once you have your recommended channel:

1. Open your router's settings (usually by typing `192.168.1.1` or `192.168.0.1` in a web browser).
2. Log in (check your router sticker for the default username/password).
3. Find **"Wireless Settings"** or **"WiFi Settings"**.
4. Look for **"Channel"** – change it to your recommended number.
5. Save the settings and wait 30 seconds for the router to restart.

Your WiFi should now be faster and more stable!

## ❓ Frequently Asked Questions

### Is this tool safe to use?
Absolutely. It reads network information only – it never connects to any network, changes settings, or transmits data.

### Will this work on my laptop/PC?
If your Windows computer has WiFi built-in, it works. No special adapter needed.

### Does it work on Mac or Linux?
This version is **Windows-only**. Mac users can use the built-in Wireless Diagnostics tool; Linux users can use `iwlist`.

### How often should I re-scan?
Run it weekly or after changing your setup (new router, moved furniture, new neighbors).

### What if the recommended channel is already used?
The tool always picks the **least congested** channel. If two are equally good, it picks the one with stronger signal.

## 🛠️ Troubleshooting

### Problem: "No adapter found"
- Make sure WiFi is turned on (check your laptop's WiFi switch or button)
- Update your wireless adapter driver (check manufacturer's website)

### Problem: Scan shows no networks
- Move closer to a router or away from thick walls
- Temporarily turn off VPN or firewall software (some block scanning)

### Problem: The file won't open
- Right-click the file → **Properties** → Check "Unblock" box → Apply
- Re-download if the file was corrupted
