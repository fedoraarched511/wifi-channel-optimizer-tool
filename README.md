Scan nearby networks, see channel congestion for 2.4 GHz and 5 GHz, and get a recommendation for the least crowded channel - no router app required on the PC.

## Features

- Scans all visible nearby networks and their active channels
- Congestion score per channel from 0 to 100
- Recommends optimal channel for both 2.4 GHz and 5 GHz
- Signal strength updated in real time
- Export scan results to CSV for comparison over time

## FAQ

**Do I need to access my router settings?**  
Yes - you'll need to log into your router to change the channel. This tool only tells you which channel to choose.

**Why is 5 GHz more congested than 2.4 GHz?**  
5 GHz has shorter range, so nearby networks in the same building appear more clearly in scans.
